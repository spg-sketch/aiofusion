What the action does, mechanically
The brief says: "Search the web for [project] in [region] (last [date range]). Return link / publication / reach / score out of 10 from Claude, Gemini, ChatGPT, Perplexity and CoPilot, bucketed by content type."

That's two API jobs stacked together:

Discovery — find ~10 pieces of brand coverage on the open web (links + publication + snippet)
Scoring — for each LLM, run a handful of representative user queries about the brand's space and check whether each discovered URL / publication / spokesperson actually surfaces in that LLM's answer. The 0-10 score is essentially "how citation-worthy does this LLM treat this piece"
Cost stack per single search run

Step	Calls	Indicative cost
Web discovery (Perplexity Sonar Pro / Tavily / Brave)	1-2 grounded calls	$0.10 - $0.30
LLM scoring — 5 engines × ~5 representative brand queries each (grounded / web-enabled)	~25 calls	$0.50 - $2.50
Aggregation + bucket / format pass (one cheap LLM call)	1	$0.05 - $0.20
Total per Run AI Coverage Search		~£0.50 - £2.50 (call it ~£1-2 working)
Things that move the number around

Microsoft CoPilot has no public scoring API — you'd be proxying Bing Search or scraping, which is cheap but adds maintenance cost
Volume of results found — a project with 50 pieces of coverage costs ~5× a project with 10
Caching — if two clients in similar categories share representative queries, marginal cost drops a lot
Trajectory — LLM API pricing has dropped 30-50% year-on-year for two years running, so the same search will likely cost half this in 12 months
Detailed Search (the secondary panel) is materially cheaper, ~£0.10-0.30, since it's narrowly scoped to one spokesperson + one title
What that means at platform-scale

If you assume each project runs the search say weekly — that's roughly £4-8 per project per month in API cost on the Earned Media Tracker alone. Add the Marketing Intelligence search (similar architecture, similar cost) and you're looking at £8-15 per project per month in raw inference cost across the two AI search modules.
