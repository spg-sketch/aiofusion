Landing Page → Platform
1. Landing Page - Visitor sees hero, features, sections for Agencies / B2B / For
Agents, guide banner, and CTA. Clicks &quot;Platform Login&quot; to enter the app.
Inside the Platform (GEO Workflow)
2. Dashboard -  Admin Overview of all clients with health scores, trends, and
quick status cards. Pick a client to work on.
Client View: 
3. Client Intake - Add a new client: company name, website, sector, description,
keywords. This is the starting point for any new engagement.
4. AIO Diagnostic -  Runs an AI-powered audit of the client&#39;s website against
GEO readiness criteria (content structure, schema, authority signals, AI
discoverability). Produces a scored report with prioritised recommendations.
5. LLM Visibility -  Sends real probe questions to ChatGPT and Claude to
check whether the client&#39;s brand is being mentioned by AI. Shows a visibility
score, per-model breakdown, competitors being recommended instead, and
interpretation caveats.
6. Content Optimiser -  Takes the diagnostic findings and helps rewrite/improve
content for better AI visibility (structure, entity clarity, citation-worthiness).
7. SEO Assessment -  Technical audit of a URL: meta tags, headings, schema
markup, links, images, AI crawler readiness, plus Google PageSpeed scores.
Returns scored findings with prioritised fixes.
8. Authority Planner -  Plan and track authority-building activities (backlinks,
citations, PR mentions) that strengthen the client&#39;s position in AI model
training data.
9. Archive (locked) - Future: historical snapshots of past audits and reports.
10. Release Gateway (locked) -  Future: approval workflow for publishing
optimised content.
11. Measure &amp; Report - View the client&#39;s GEO report with scores, trends, and a
&quot;Start Implementing&quot; button that loops back to Content Optimiser.

The Loop: Intake → Diagnose → Visibility Check → Optimise → Plan →
Measure → Repeat
The idea is that after measuring results, you run the LLM Visibility check again to see
if the score has improved, then repeat the cycle. 
Each pass should move the needle on AI citations.
