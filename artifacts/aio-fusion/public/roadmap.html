5. Key Decisions Log
Agreed in August 2026 planning session
5
Decisions confirmed — Spencer, Patrick & Natalie
Environment 🔒
Live demo frozen from July 2026
No structural changes to the live platform until cutover. All build work happens on staging only.
Dependency order 📋
Staging first — everything else depends on it
Staging environment must be fully set up and verified before any login, payment, or permissions work begins.
Access control 💳
No admin approval gate — Stripe payment = access
The manual admin approval queue is removed. A completed Stripe payment is the only gate to platform access. Admins can grant a free-access flag for beta/demo accounts.
Terminology 🏷
Agency/Partner — not Reseller — in all user-facing strings
"Reseller" does not appear anywhere visible to users. All UI, marketing pages, and emails use "Agency/Partner".
SSO 🔑
Microsoft Entra ID — not Teams SSO
"Sign in with Microsoft" using Microsoft Entra ID (formerly Azure AD). "Teams SSO" is not used anywhere.
Seat limits 👥
3 seats per account across all non-master tiers
Agency/Partner: 3 seats. Client accounts: 3 seats each. Standalone clients: 3 seats. All limits stored in the DB and configurable per account.
Security 🛡
MFA mandatory for master accounts (TOTP)
Time-based one-time password (TOTP) required for all master-level accounts. Not enforced for other tiers at launch.
Data retention 🗄
Hard-delete: 30-day recovery window; financial records 6 years
Deleted accounts/projects move to soft-delete state for 30 days before permanent removal. Financial records (invoices, payments) retained for 6 years per UK accounting law.
Deferred ⏸
Post-launch deferrals confirmed
Multi-workspace membership (one user, multiple companies), dormant project storage fee, and seat add-ons are all deferred to post-launch releases.
